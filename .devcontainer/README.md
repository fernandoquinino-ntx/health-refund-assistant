# Configuração do Dev Container

[`devcontainer.json`](./devcontainer.json) é configuração de infraestrutura reconhecida pelo GitHub
Codespaces e pela extensão Dev Containers do VS Code. Ele define a imagem Python,
instalação do projeto, extensões recomendadas e encaminhamento da porta da aplicação.
Não é arquivo de configuração do assistente nem dataset JSON. Consulte a
[documentação específica](./devcontainer.md).
