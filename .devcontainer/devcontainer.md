# `devcontainer.json`

Configuração de infraestrutura reconhecida por GitHub Codespaces e Dev Containers do
VS Code. Define ambiente de desenvolvimento, dependências/extensões recomendadas e
encaminhamento de portas.

Não é configuração funcional do assistente nem dataset da aplicação. Seu formato é
definido pelo padrão Dev Container, não pelos schemas internos do projeto.
