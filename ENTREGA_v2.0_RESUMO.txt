🎯 PRÓXIMOS PASSOS:

  1. Descompacte o ZIP:
     $ unzip health-refund-assistant-v2.0-final.zip
     $ cd health-refund-assistant

  2. Leia (3-5 min):
     $ cat docs/00_guia_rapido_inicio.md
     $ cat docs/00_mapa_estrutura.md

  3. Escolha seu perfil em docs/00_mapa_estrutura.md:
     → Novo usuário: docs/10_quickstart/01_comece_aqui.md (10 min)
     → Revisor: docs/60_project/01_caderno_projeto.md (1-2h)
     → Executor: docs/40_testing/03_verificacao_codespaces_ui.md (20 min)
     → Arquiteto: docs/50_architecture/02_ai_agent_architecture.md (1-2h)
     → Apresentador: docs/60_project/02_apresentacao_grupo.md (30 min)

  4. Configure o ambiente:
     $ python3 -m venv .venv
     $ source .venv/bin/activate  # macOS/Linux
     $ pip install -r requirements.txt

  5. Execute testes:
     $ pytest -v

  6. Rodar UI (Streamlit):
     $ python app.py
     # Acessa: http://localhost:8501

  7. Preencha resultados (antes de 02/12/2026):
     $ docs/70_documentation/07_planilha_testes_5_casos.md

  8. Gere ZIP final para entrega:
     $ git archive -o health-refund-assistant-final.zip HEAD
