# `manifest.json`

Metadados obrigatórios da extensão Chrome Manifest V3, como nome, permissões, scripts
de serviço e interfaces. É consumido pelo Chrome; não é uma exportação de reembolsos.

Os JSONs de exportação baixados pela extensão são arquivos separados. Ao importá-los
na aplicação, uma cópia validada é salva em `json/plan/imports/`.
