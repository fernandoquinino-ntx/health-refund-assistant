# `notes_state.schema.json`

Contrato JSON Schema Draft 2020-12 do índice local
[`json/documents/state/notas_extraidas.json`](../documents/state/notas_extraidas.json). Valida
registros de PDFs processados, resultados de extração e duplicatas. O arquivo de estado
pode conter dados pessoais/de saúde; o schema não contém esses dados.
