# `avaliacao.json`

Relatório local e regenerável do benchmark VLM, produzido por
`python -m toolbox avaliar`. Registra os resultados observados para uma
execução da bateria; não contém o gabarito como entrada do modelo.

- **Contrato:** [vlm_evaluation_report.schema.json](../schemas/vlm_evaluation_report.schema.json).
- **Privacidade:** relatórios de dados reais podem repetir informações pessoais; use
  fixtures sintéticas para compartilhar.
