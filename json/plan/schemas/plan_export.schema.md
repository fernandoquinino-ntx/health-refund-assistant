# `plan_export.schema.json`

Contrato JSON Schema Draft 2020-12 para exportações do plano de saúde. Valida datasets
importados em `json/plan/imports/` e a exportação fictícia em
`json/tests/synthetic/exportacao_ficticia.json`.

O código verifica também se o período informado é válido antes de usar a exportação.
Este arquivo descreve formato e tipos; não contém dados reais.
