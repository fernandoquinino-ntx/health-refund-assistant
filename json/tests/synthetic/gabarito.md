# `gabarito.json`

Ground truth sintético gerado a partir de
`json/tests/templates/gabarito.template.json` e usado somente pelo avaliador para
comparar as respostas.

- **Contrato:** [test_gold.schema.json](../schemas/test_gold.schema.json).
- **Dados:** fictícios; pode ser versionado.
- **Segurança:** nunca enviar ao prompt ou ao modelo avaliado.
