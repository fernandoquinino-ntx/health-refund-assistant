# `casos_teste.template.json`

Template-fonte versionado do manifesto dos cenários. O gerador sintético o copia para
`json/tests/synthetic/casos_teste.json` e cria os PDFs em
`data/sinteticos/documentos/`.

- **Contrato:** [test_cases.schema.json](../schemas/test_cases.schema.json).
- **Conteúdo:** entradas, referências a documentos, perguntas e metadados dos casos.
- **Não incluir:** gabaritos nem dados reais de saúde.
